# Шрифт Manrope

Файлы лежат здесь, внутри дизайн-системы, а не тянутся с серверов Google, по двум причинам:
сборка на российском сервере может до них не достучаться (`deploy/deploy.sh`
делает `git pull && build` прямо на машине), а зарубежные сервисы §8 держит
снаружи. Шестьдесят килобайт в репозитории дешевле, чем сборка, которая
падает или молча отдаёт системный шрифт.

| Файл | Что покрывает | Размер |
|---|---|---|
| `manrope-latin.woff2` | латиница, знаки препинания, «кавычки», тире, − | 25 КБ |
| `manrope-latin-ext.woff2` | расширенная латиница и **знак рубля ₽** | 15 КБ |
| `manrope-cyrillic.woff2` | кириллица и знак номера № | 14 КБ |

Знак рубля живёт в расширенной латинице, а не в основной — без этого файла
все суммы теряли бы «₽» в системный шрифт. Знак номера — в кириллице,
он нужен для «Заказ № 1240».

Браузер скачивает только те файлы, символы которых встретились на странице:
это делает `unicode-range` в `@font-face` (`src/app/globals.css`). Файл
один на все начертания — Manrope переменный, вес 200–800 внутри одного файла.

Версия v20 из Google Fonts, лицензия SIL Open Font License 1.1 — `OFL.txt`.
Лицензия разрешает класть файлы в репозиторий при условии, что её текст
лежит рядом. Обновлять незачем: шрифт не меняется.
