# Спринт 02 — месяц 2, бюджет 62 часа

**Цель месяца:** клиент открывает витрину, видит настоящие карточки услуг
и может выбрать нужную. Подрядчик заводится на площадку сам.

Сделки, документов и оплаты по-прежнему нет: сначала должно быть что заказывать
и у кого. Заказ из каталога — спринт 04.

---

## 02-1. Витрина: каталог, фильтры, карточка услуги — 24 ч

Основной путь клиента (§1 `CLAUDE.md`). Экраны рисуются по утверждённым макетам
из `design/`: `Main.dc.html` и `Listing.dc.html`.

**Сделать:**

- Публичный каталог: сетка карточек, фильтр по категории и зоне, сортировка
- Карточка услуги: цена, что входит, подрядчик с проверенным ИНН, блок
  «Как защищена сделка»
- Поиск по названию и описанию — простое совпадение по строке, без полнотекстового
  индекса: на первой сотне карточек разницы нет, а индекс это отдельные часы
- Публичный интерфейс `catalog`: `searchListings({ categoryId, zoneCode, query, limit, offset })`
- Четыре состояния каталога: пустой результат фильтра, загрузка, ошибка, успех

**Готово, когда:**

- Клиент находит услугу по категории и зоне и открывает её карточку
- Пустой результат фильтра объясняет, что изменить, и содержит кнопку сброса
- В каталоге видны только карточки в статусе `published`
- Страница не едет вбок при 360 px

## 02-2. Саморегистрация подрядчика и верификация ИНН — 22 ч

Решение Q10: каталог наполняется саморегистрацией, а не руками оператора.

**Сделать:**

- Форма регистрации подрядчика: ИНН, название, контактное лицо, почта
- Проверка ИНН через справочник (провайдер — Q11), с запасным путём:
  справочник не ответил или ответил неуверенно → заявка в очередь оператору
- `platform.orgs.inn_verified_at` и `inn_verification` заполняются всегда:
  через полгода надо уметь ответить, на основании чего компанию пустили
- События `contractor.registered` / `verified` / `rejected` в outbox
- Экран оператора: очередь регистраций, требующих ручной проверки

**Готово, когда:**

- Подрядчик регистрируется сам и попадает в статус `draft` до проверки
- Есть тест: недоступный справочник не ломает регистрацию, а отправляет её оператору
- Есть тест: повторная регистрация с тем же ИНН не создаёт вторую компанию
- Ни один внешний вызов не может остановить регистрацию (`docs/01-architecture.md`)

## 02-3. Кабинет клиента: компания и объекты — 16 ч

**Сделать:**

- Карточка компании клиента: реквизиты, контакты, кто имеет доступ
- Объекты клиента: адреса точек с зоной из `catalog.listZones()`.
  Коды зон руками не вводятся — иначе опечатка молча обнулит подбор
- Приглашение сотрудника в компанию по почте

**Готово, когда:**

- Клиент заводит вторую точку и видит обе
- Есть тест: сотрудник одной компании не видит объекты другой,
  даже подставив идентификатор в адрес
