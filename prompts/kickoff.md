## Промпт для ревью перед деплоем

Проверь последние изменения по этому списку и ответь по каждому пункту
«да / нет / неприменимо» с конкретной ссылкой на файл:

1. Все суммы — `bigint` в копейках, нигде нет `float` и `number` для денег
2. Все временные метки — `timestamptz`, записываются в UTC
3. Валидация входа через Zod на сервере, а не только в форме
4. Права проверяются в серверных экшенах, а не в компонентах
5. Нет JOIN между схемами модулей и нет импортов глубже `index.ts`
6. Побочные эффекты идут через outbox, а не выполняются в обработчике запроса
7. Обработчики событий идемпотентны
8. Ни один внешний вызов не может остановить сделку — везде таймаут и запасной путь
9. Персональные данные не уезжают за пределы РФ, включая логи и сервис ошибок
10. Новых зависимостей нет, либо каждая обоснована отдельно
11. Цвета, размеры и отступы взяты из токенов, а не заданы по месту
12. Обе темы определены, ни один цвет не живёт только внутри тёмной
13. Нет фиксированных ширин, таблицы в контейнере с горизонтальной прокруткой,
    страница не едет вбок при 360 px
14. Ничего важного не доступно только через hover; целевые области не меньше 44 px
15. У каждого нового экрана описаны четыре состояния: пустое, загрузка, ошибка, успех

Если по какому-то пункту «нет» — предложи правку, не оправдание.
